# HTML Agent

附着在本地多页 HTML 上的**只读问答助手**。解释页面、搜索授权目录、读取相关资料；修改需求只提供建议，绝不修改原文件。

## 运行

需要 Node.js 22.13 或以上，无需编译或注册全局命令。首次使用或更新依赖后，在本仓库根目录安装锁定版本依赖：

```bash
npm ci --prefix html-agent --ignore-scripts
```

Markdown 渲染使用本地提供的 Marked 与 DOMPurify；文档提取使用 OfficeParser，不依赖浏览器 CDN、系统 Office 或外部转换命令。然后配置模型并启动：

```bash
# 选择支持流式 Chat Completions 与工具调用的模型服务。
export HTML_AGENT_BASE_URL='https://你的模型服务/v1'
export HTML_AGENT_MODEL='你的模型名称'
# 在自己的终端安全设置 HTML_AGENT_API_KEY，不要把密钥发到对话或写入 HTML。
node html-agent/src/cli.mjs open '/你的项目/演示/首页.html' --root '/你的项目'
```

默认模型地址为 `https://api.openai.com/v1`。远端服务需要 `HTML_AGENT_API_KEY`；回环地址上的本机兼容服务可以省略密钥。远端必须使用 HTTPS。没有模型配置时仍能打开页面，面板会提示如何启用问答。

- `--root`：Agent 读取范围，也是页面静态资源的站点根目录，含所有子目录；必须包含入口 HTML 及其依赖的本地资源。不指定则使用入口所在目录，**不自动向上授权**。
- `--port`：文档服务端口，默认自动分配；聊天面板使用另一自动分配端口。
- `--no-open`：仅输出入口链接，不自动打开浏览器。
- `--help`：完整帮助。
- 退出：终端按 `Ctrl+C`，停止两个端口并清除内存对话。

启动前查看明确打印的授权根目录。不要授权整个主目录，不要在命令参数中传入密钥。服务不会创建配置、索引或对话文件。

## 目录与多页跳转

```text
项目/                       ← --root
├── 资料/产品说明.md
├── 演示/首页.html            ← open 的入口
├── 演示/详情/分析.html
└── 附录/补充说明.html
```

在分析页也能读取资料和附录。保持原目录结构，支持相对链接、以 `/` 开头的根相对链接、查询参数、锚点及目录中的 `index.html`。每个 HTML 响应自动加入助手，原文件不会改变。使用启动器的完整入口链接打开，而不是直接双击 `file://` 文件。

### 样式与共享资源

入口 HTML 所在目录不一定是完整站点的根目录。例如：

```text
课程项目/                    ← --root
├── index.html
├── assets/course.css
├── assets/course.js
└── lessons/第一课.html       ← open 的入口，引用 ../assets/course.css
```

此时应以 `课程项目` 为根目录，而不是 `lessons`：

```bash
node html-agent/src/cli.mjs open '/课程项目/lessons/第一课.html' --root '/课程项目'
```

若只授权 `lessons`，父目录中的 CSS、JS、图片和首页不在服务范围内，会出现资源加载失败、页面无样式或跳转失败。修改 `--root` 后须重启服务并使用新的完整入口链接；无需改动 HTML 或复制资源。

**扩大 `--root` 也会扩大 Agent 可读取的范围**，不是只开放样式。先确认共同父目录可授权；工具不会为加载资源自动向上查找或绕过边界。仍有资源加载失败时，检查文件是否存在、链接大小写及是否命中安全排除规则。

同一标签页跳转后保留最近五轮成功对话，当前页面与选区重新采集。进行中的回答随跳转取消。会话闲置两小时过期，重启服务清除全部记录；不持久化到磁盘。禁用会话存储时无法保证跨页保留。新标签页的浏览器复制行为可能继承原会话，需独立讨论时清空对话或重新打开完整入口链接。

## 页面组件

无需向 HTML 添加任何代码。通过启动器打开后，控制台可使用：

```javascript
window.HTMLAgent.unmount(); // 移除面板、节点与监听器，取消面板连接
window.HTMLAgent.mount();   // 使用本次启动配置重新挂载
```

这是本地站点内的可插拔组件，不是任意线上网页到本机目录的开放接口。注入脚本地址使用绝对 URL，不受页面 `<base>` 标签影响。面板样式封装在 Shadow DOM 与独立来源 iframe 中，不向文档注入全局 CSS。

## 只读工具与范围

| 工具 | 能力 |
|---|---|
| `list_files` | 递归列出根目录或指定子目录中未被安全规则排除的普通文件（可列出不代表可解析），最多返回 200 项 |
| `search_files` | 按字面文本搜索，返回相对路径、行号和片段，最多返回 30 处匹配 |
| `read_file` | 读取文本或提取文档文字，最多 200 行、16,000 字符 |

文件支持范围：

| 类型 | 读取方式 |
|---|---|
| 源代码、配置、日志、CSV、HTML、Markdown 等 | 不限制扩展名，支持 UTF-8，以及带 BOM 的 UTF-16 LE/BE；包括 Go、Python、SQL、Shell、TOML 和无扩展名文件 |
| PDF | 提取已有文本层；扫描件需要用户先 OCR |
| DOCX、XLSX、PPTX | 提取文字与表格等可读内容，不执行宏、不重算公式、不还原视觉排版 |
| ODT、ODS、ODP、RTF、EPUB | 提取文档文字 |
| 旧版 DOC／XLS／PPT、加密或损坏文档 | 明确提示原因，建议解密或另存为支持的格式；不会自行转换或改写 |
| 图片、音视频、通用压缩包及其他二进制文件 | 可列出文件名，但不执行 OCR、转录或任意解压，不能读取其正文 |

纯文本及 HTML 单文件上限 1 MiB，文档输入上限 20 MiB，提取文本最多 1 MiB 并标记截断。文档解析在可终止的工作线程中进行，同时最多解析两份，每份最多 10 秒，限制 JavaScript 堆为 128 MiB、解压总量为 32 MiB、压缩包条目为 3,000、表格单元格为 100,000；支持取消。只向解析器传入通过权限检查的文件字节，不传入路径或 URL，不启用 OCR、附件提取或临时文件输出。

文档行号是**提取文本的行号**，不是原文档行号或 PDF 页码。解析警告、搜索跳过文件和截断均返回给模型并显示在读取记录中，不能据此声称已读取全部内容。搜索最多处理约 8 MiB 可读正文数据、持续 15 秒；图片、音视频和其他已识别的二进制文件只读取最多 4 KB 的前缀用于判断，不消耗正文搜索预算；结果会分别标注不支持、超大、预算不足和读取失败的文件。目录遍历最多检查 3,000 个条目、收集 1,000 个普通文件、深入 20 层。其他页面静态资源上限 32 MiB。

隐藏路径（含 `.env`、`.git`）、依赖目录、常见密钥／凭据文件、符号链接、硬链接默认排除。普通文件名中的敏感内容无法自动识别，**授权目录须由用户自行筛选**。Agent 没有写入工具、Shell、任意代码执行或联网搜索工具。

## 模型与隐私

首次提问前确认数据发送：当前页面文本、选区、最近五轮成功对话与按需读取的资料片段会发送给所配置的模型服务。模型密钥只在服务端，不放入 HTML 或浏览器存储。聊天面板展示根目录、模型服务和工具调用记录。回答支持 Markdown 标题、列表、表格、引用、链接和代码块，可复制代码；流式回答和跨页恢复使用同一渲染逻辑。表格与长代码局部横向滚动，上翻阅读时不强制滚回底部。工具记录默认折叠，失败记录展开并保留文件路径与原因。Markdown 经过标签白名单净化，原始 HTML 作为文字显示，不加载模型提供的图片，不执行脚本或命令；链接仅在用户点击后于新窗口打开。

工具调用过程中的模型草稿和参数纠错不会展示给用户；只有成功拿到最终回答才会开始输出。工具参数错误会作为工具错误返回给模型，允许继续修正，直到成功、用户停止或达到上限。每轮最多 12 次工具调用、6 次模型请求、120 秒。可停止回答；失败或取消的轮次不写入成功历史，可重试。接口需兼容 SSE 流式 Chat Completions 的工具调用协议；不是所有标注“兼容”的模型服务都支持这些能力。

## 安全与兼容边界

- **仅打开可信 HTML。** 原页面脚本仍会执行并能访问同站点允许的资源；这不是恶意网页沙箱，不能阻止原页面自行联网或泄露其可访问的数据。
- 两个服务仅绑定 `127.0.0.1`。完整启动链接是临时访问凭证，不要分享或暴露端口。文档与面板分来源；API 校验独立凭证、主机与来源，不向文档开放 CORS。
- 仅保证普通静态 HTML 及其本地链接。写死的 `file://`、跨站地址、Canvas、跨域 iframe、需要后端 API 的页面和严格 CSP 页面不保证助手可用，不删除页面原有 CSP。
- HTML 不超过 1 MiB，编码须为 UTF-8；媒体不提供 Range 流式服务，不面向大型视频站点。
- `/__html_agent__/` 是保留路径。禁止注册 Service Worker，避免在原目录留下持久化浏览器拦截。
- 当前先在 Chromium 浏览器验收；其他现代浏览器需要支持 iframe 会话存储和流读取。没有自动修复第三方 HTML 的能力。

## 插件安装

可直接运行本目录，无需安装插件。若希望编码 Agent 通过 skill 启动：

- Codex：按仓库根目录 `codex-plugin-add.md` **合并** `html-agent` 条目与插件目录，不覆盖已有市场配置。
- Claude Code：先添加市场来源，再选择 `html-agent`：

```text
/plugin marketplace add https://github.com/Y2138/zz-agent-plugins
/plugin install html-agent@zz-agent-plugins
```

双端使用同一 skill 和本地运行时。技术范围见《方案》。
