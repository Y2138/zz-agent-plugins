# 生成 Skill 验证协议

交付生成的 project prototype skill 之前，做一个小型正向测试。

## 验证任务

选一个小而有代表性的页面需求，例如：

```text
创建一个列表页原型，含筛选、表格、空态和主操作按钮。
```

以生成的 skill 作为唯一设计权威。结果应证明该 skill 可被未来的 agent 使用，无需重读原始项目。

## 检查项

- 生成的 skill 是否能在项目专属原型请求时正确触发？
- `SKILL.md` 是否指向正确的 reference 文件？
- 生成的 skill 是否捕获了原始 UI 技术栈和组件库？
- 是否要求原型产出为独立 HTML？
- Design Token 是否语义化命名并标注证据/置信度？
- 组件模式是否足够具体，其他 agent 可直接复用？
- 样本原型是否匹配项目密度、布局、状态和视觉风格？
- 样本原型在浏览器中打开是否无控制台错误、无白屏、无明显渲染破碎？
- 假设和未解决冲突是否可见？
- 生成的 skill 是否避免了不支持的视觉花样？

## 浏览器预览

当生成的 skill 创建了样本 `prototype.html` 时，生成后在浏览器中打开。

验证：
- 页面不白屏
- 控制台无 JS 错误
- 关键布局区域可见
- 文字无明显截断或重叠
- 引用的资产和 CDN 依赖加载成功或有安全降级
