# project-ui-prototyper · 项目一致原型生成

基于已有项目 UI 规则，从 PRD、草图、线框图生成与项目一致的 DESIGN.md 和 HTML 原型。

## 能力

- **项目 UI 规则消费**：加载 project skill 或 design tokens/组件模式/布局规则
- **需求到模式映射**：将 PRD 页面/流程自动映射到最接近的已有项目页面原型
- **DESIGN.md 生成**：面向页面的精简设计规格
- **HTML 原型生成**：独立 `.html` 文件，双击可开，无需构建步骤
- **草图/线框图解读**：提取布局意图，应用项目视觉系统
- **浏览器预览验证**：交付前检查 JS 错误和渲染问题

## 触发词

项目原型、PRD转原型、草图转原型、线框图转原型、页面还原、UI还原、设计还原、project prototype、sketch to prototype、wireframe to HTML
