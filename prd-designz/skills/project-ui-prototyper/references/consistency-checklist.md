# 项目 UI 一致性检查清单

交付前执行。

## 必检项

- [ ] 原型使用了项目 Design Token（色彩、排版、间距、圆角、阴影、断点）
- [ ] 原型可行时使用了原始项目 UI 框架/组件库，或说明了原生 HTML/CSS/JS 降级原因
- [ ] HTML 产出为**一个独立 `.html` 文件**，无构建步骤或多文件依赖
- [ ] 原始字体、Logo、图标、图片等资产已内嵌、可通过稳定 URL 访问或替换为显式占位符
- [ ] 有可复用项目 UI 脚手架（`assets/`）时已用于固定外壳：侧栏/顶栏 admin 框架、页面外壳、抽屉、模态框或仪表盘网格
- [ ] 组件匹配项目变体、尺寸、密度、图标风格和状态行为
- [ ] 布局映射到已知项目页面原型或说明了最小扩展
- [ ] 导航、面包屑、工具栏、筛选器和操作按钮遵循项目惯例
- [ ] 加载、空、错误、禁用、选中、成功状态匹配项目模式
- [ ] 草图或 PRD 特定假设可见
- [ ] 文字在目标视口尺寸范围内适合容器
- [ ] 未引入项目不支持的渐变、装饰性卡片、外来图标集或不相关视觉语言
- [ ] 浏览器预览完成：无 JS 错误、无白屏、无关键资产缺失、无明显布局破碎
