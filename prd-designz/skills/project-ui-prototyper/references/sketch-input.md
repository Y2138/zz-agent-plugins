# 草图与线框图输入

使用草图和线框图理解布局和意图，而非视觉样式。

## 从草图中提取

- 页面区域和层级
- 内容分组
- 导航位置
- 主操作位置
- 重复项结构
- 用户流程顺序
- 标注的状态或约束

## 不复制

- 手绘视觉样式
- 草图中的任意间距
- 未标注的装饰元素
- 与项目 UI 系统冲突的组件

## 映射流程

1. 将草图区块翻译为语义化区域
2. 将每个区域映射到已有项目组件
3. 应用项目 Token、密度、排版、状态和布局规则
4. 保留用户的意图层级，除非与可用性或项目惯例冲突
5. 不明确的草图区域标注为假设

## 澄清问题

仅在草图无法回答时提问：

- 用户的主操作是什么？
- 这是列表页、详情页、创建页、审核页还是仪表盘？
- 哪些数据是必需的，哪些可选？
- 需要展示哪些状态？
