# 反 AI Slop 清单

AI slop = AI 训练语料里最常见的「视觉最大公约数」。这些东西不代表丑，而是不携带任何品牌信息。

**核心逻辑**：用户请你做设计，是要品牌被认出来。AI 默认产出 = 训练语料的平均 = 所有品牌混合 = 没有品牌被认出来。

## 核心要规避的

| 元素 | 为什么是 slop | 什么时候可以用 |
|---|---|---|
| 激进紫色渐变 | AI 语料里「科技感」万能公式 | 品牌本身用紫渐变 |
| Emoji 作图标 | 每个 bullet 都配 emoji 是病 | 品牌本身用（如 Notion） |
| 圆角卡片 + 左彩色 border | 2020-2024 烂大街组合 | 品牌设计规范里保留 |
| SVG 手画人物 / 场景 | AI SVG 人物五官错位 | 几乎没有——用真图或 placeholder |
| CSS 剪影代替产品图 | 任何产品都长一样，识别度归零 | 几乎没有——走品牌资产协议 |
| Inter / Roboto / Arial 作 display | 太常见看不出是「有设计的产品」 | 品牌规范明确用 |
| 全场 `#0D1117` 深蓝底 | GitHub dark 复制品 | 开发者工具且品牌走这方向 |
| 装饰性 stats / 数字 / 图标 | 没用的数据噪音 | 数据是真的且有用 |
| 每个标题都配 icon | icon 滥用 = 视觉噪音 | icon 承载差异化信息时 |
| 所有背景都渐变 | AI 默认填充策略 | 渐变是品牌签名时 |
| 无来源的产品事实 / 科普结论 | 训练语料记忆会过期或错配 | 写入 Fact Ledger，未验证就标注 uncertain |
| Stock 图冒充真产品/真地点/真事件 | 视觉会把用户带到错误事实 | 只用可追溯图片，缺失就 placeholder |
| 4 个方向都是安全极简 | 没有扩大选择面，只是在预设答案 | 使用方向采样三锚点重做 |

**判断边界**：「品牌本身用」是唯一能合法破例的理由。

## 正向做什么

- **`text-wrap: pretty`** + CSS Grid + 高级 CSS：排版细节是品味信号
- **用 `oklch()` 或品牌已有色**，不凭空发明新颜色
- **配图优先真实素材**（Wikimedia / Unsplash / AI 生成），不用 SVG 手画
- **事实优先证据**：页面文案和视觉锚点来自已验证来源，不来自模型记忆
- **内容型作品先找图**：科普、海报、品牌官网、产品展示先补主视觉，再做高保真
- **一个细节做到 120%，其他做到 80%**：品味 = 在合适的地方足够精致，不是均匀用力
- **减法优先**：少一层容器、少一个 border、少一个装饰性 icon——给内容留气口

## 例外：信息密度型产品

当产品核心卖点是「智能 / 数据 / 上下文感知」（AI 工具 / Dashboard / Tracker / Copilot）：
- 每屏至少 3 处**有内容的**差异化信息（非装饰性数据、推理片段、状态推断）
- 这是加法优先——加的是有内容的密度，不是装饰
- 装饰性 icon 照样忌讳

## 自检方法

每完成一个原型页面，过一遍：

正向检查：
1. 去掉所有颜色，只剩黑白灰——信息层级仍然清楚吗？
2. 去掉所有 icon——用户仍然知道怎么操作吗？
3. 删掉所有未验证事实——页面仍然能成立吗？

红线检查：
1. 把品牌名换成竞品名——是否几乎看不出区别？
2. 去掉所有图片——是否暴露出页面其实没有内容主体？
3. 4 个方向并排看——是否只是同一种极简的颜色/圆角变化？

正向检查有任何「否」，或红线检查有任何「是」，说明设计依赖 slop 元素而非品牌 DNA。
