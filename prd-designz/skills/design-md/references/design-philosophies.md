# 12 种设计哲学

4 个流派，每派 3 种。Fallback 时从 4 派各取 1 个，推荐 4 个差异化方向。

本文件用于扩大设计方向，不用于把所有方案收敛成同一种「安全极简」。方向顾问阶段必须先扩散，再让用户选择风险档位。

---

## 方向采样三锚点

当用户没有明确风格，或要求「高级感」「创意」「强视觉」「不普通」时，在给 4 个方向前先做三锚点采样。

### Anchor A · 随机设计哲学

从下方 12 种设计哲学中抽取 1 个作为随机扰动项。

执行规则：
- 不得总是选择 Swiss / Apple Minimalism / Dark Luxury
- 如果任务是后台、工具、SaaS，也仍然可以抽到 Editorial Grid、Neo-Brutalism、Generative Art，但需要解释如何降噪落地
- 如果抽到高风险方向，只借用结构、节奏、比例或交互逻辑，不强行套满视觉皮肤

### Anchor B · 获奖/高水准作品结构

搜索或引用 1 个获奖/高水准作品，只借鉴「结构手法」。

可借鉴的结构手法：
- 首屏如何建立主体识别
- 图文比例和裁切方式
- section 之间的节奏变化
- 视觉焦点如何从一个屏幕过渡到下一个屏幕
- 文字层级如何承担叙事，而不是只做装饰

禁止：
- 照搬配色、Logo、插画、摄影主体
- 把获奖站的电影感动画直接套到生产级后台
- 用「像某某获奖作品」替代对当前任务的判断

### Anchor C · 顶级设计师/机构方法

选择 1 位设计师或机构的方法，重新解释需求。

示例方法：
- Kenya Hara / MUJI：从「去掉什么」开始，让信息留出呼吸
- Massimo Vignelli：用网格、字重和比例建立严谨秩序
- Paula Scher / Pentagram：让文字成为图形和品牌记忆点
- Dieter Rams：减少视觉噪音，只保留可理解的功能层级
- Field.io / Active Theory：把互动和运动作为叙事材料
- IDEO / frog：从用户场景和原型验证开始，而不是从装饰开始

执行规则：
- 写清「借用的方法」而非只写人名
- 生产级 Web App 只借用可落地方法，不复制高维护成本视觉效果
- 如果事实或资产不足，先回到 Fact Ledger 和图片门禁

## 一、理性建构派

气质：克制、秩序、信息密度。适合：企业级产品、数据密集型应用、专业工具。

### 01 · Swiss / International

- **代表**：Josef Müller-Brockmann, Massimo Vignelli
- **气质关键词**：精确、网格、客观、永恒
- **视觉特征**：
  - 严格网格系统（8px / 12-column）
  - 无衬线字体（Helvetica / Neue Haas / Akzidenz）
  - 黑白为主 + 单个功能色
  - 大量留白，信息层级极度清晰
- **适合**：SaaS 后台、数据仪表盘、企业官网

### 02 · Material Rationality

- **代表**：Google Material Design, Vercel
- **气质关键词**：功能、一致、可预测、系统化
- **视觉特征**：
  - 清晰的 elevation 层级（shadow 表达深度）
  - 功能色明确（primary / secondary / surface / error）
  - 8dp 网格系统
  - 圆角一致，触摸目标 ≥ 48px
- **适合**：移动端 App、跨平台产品、设计系统

### 03 · Editorial Grid

- **代表**：Bloomberg, The Information, Notion
- **气质关键词**：内容优先、阅读体验、新闻编辑
- **视觉特征**：
  - 多栏布局，sidebar + 主内容区
  - 衬线 display + 无衬线 body 组合
  - 清晰的 typographic hierarchy
  - 密度适中，信息可扫读
- **适合**：内容平台、新闻应用、知识管理工具

## 二、感性叙事派

气质：情绪、沉浸、氛围感。适合：品牌展示、营销页面、生活方式产品。

### 04 · Organic Warmth

- **代表**：Airbnb, Glossier, Kinfolk
- **气质关键词**：温暖、自然、亲密、可信
- **视觉特征**：
  - 暖色调底色（cream / sand / warm gray）
  - 大圆角（16px+），柔和阴影
  - 真实摄影 > 图标和插画
  - 手写体 / 圆润无衬线字型
- **适合**：DTC 品牌、民宿 / 旅行、食品 / 生活方式

### 05 · Dark Luxury

- **代表**：Aesop, Apple Pro, Linear
- **气质关键词**：精致、克制、高级、暗调
- **视觉特征**：
  - 深色背景（#0A0A0A ~ #1A1A2E）
  - 单个金属 / 宝石色调 accent（gold / teal / violet）
  - 极细线条分隔（0.5px）
  - 大量留白，每个元素都精雕细琢
- **适合**：高端品牌、开发者工具、创意工具

### 06 · Kinetic Poetics

- **代表**：Field.io, Active Theory, Locomotive
- **气质关键词**：运动、技术美学、沉浸、实验
- **视觉特征**：
  - 全屏视觉 + 滚动驱动动画
  - 大字号 display（100px+）
  - 高对比度配色（黑底 + 荧光色 / 渐变）
  - 视差效果和过渡动效
- **适合**：创意机构、品牌发布页、产品展示

## 三、极简留白派

气质：留白、精致、少即是多。适合：高端产品、设计驱动品牌、艺术相关。

### 07 · Zen / Wabi-sabi

- **代表**：Kenya Hara, MUJI, Nendo
- **气质关键词**：留白、朴素、触感、时间感
- **视觉特征**：
  - 大量留白（60%+ 空间）
  - 自然色系（土色 / 灰色 / 素色）
  - 单个不完美元素作为视觉焦点
  - 极细字重 + 宽松字距
- **适合**：日系品牌、文化机构、高端消费品

### 08 · Apple Minimalism

- **代表**：Apple, Stripe, Linear
- **气质关键词**：简洁、精致、技术感、高完成度
- **视觉特征**：
  - SF Pro / San Francisco 字体家族
  - 极少色彩（1-2 个功能色）
  - 毛玻璃效果（backdrop-filter）
  - 精确的间距和圆角系统
- **适合**：科技产品、工具类 App、设计驱动公司

### 09 · Typography-first

- **代表**：iA Writer, Bloomberg Businessweek, Grids
- **气质关键词**：文字即设计、阅读体验、极简
- **视觉特征**：
  - 字体是唯一的视觉元素
  - 2-3 个字重变化创造所有层级
  - 极度克制的色彩（可能只有黑白 + 一个 accent）
  - 行长和行高精确控制
- **适合**：写作工具、阅读应用、极简品牌

## 四、实验先锋派

气质：破格、冲击、视觉实验。适合：创意行业、年轻品牌、艺术项目。

### 10 · Neo-Brutalism

- **代表**：Gumroad, Figma (部分), Vercel (早期)
- **气质关键词**：原始、直接、大胆、反装饰
- **视觉特征**：
  - 粗黑边框（2-4px）
  - 硬阴影（offset shadow，无模糊）
  - 高饱和色彩组合
  - 大字号 + 粗字重
- **适合**：创业公司、开发者工具、创意工具

### 11 · Generative Art

- **代表**：Tyler Hobbs, Vera Molnár, fxhash
- **气质关键词**：算法、随机、秩序中的混沌
- **视觉特征**：
  - 代码生成的几何图案
  - 受限色板（3-5 色）但排列组合丰富
  - 网格 / 重复 / 变异
  - 有机形状与数学曲线
- **适合**：NFT 平台、创意机构、艺术展览

### 12 · Cyberpunk Retro

- **代表**：Vapor95, Hack Club, Warp Terminal
- **气质关键词**：复古未来、霓虹、像素、反叛
- **视觉特征**：
  - 霓虹色（cyan / magenta / electric purple）
  - 深色背景 + 发光效果
  - 等宽字体 / 像素字体
  - CRT 扫描线 / 故障效果
- **适合**：游戏、黑客工具、Z 世代社区

## Fallback 推荐模板

当用户需求模糊时，从 4 派各选 1 个，组成推荐：

```
我为你准备了 4 个差异化设计方向：

方向 A · [流派A-某哲学] — [50字理由]
   来源锚点：[随机哲学 / 获奖作品结构 / 设计师方法]
   视觉特征：[3个特征]
   气质：[3-5个关键词]
   风险档位：[低 / 中 / 高]

方向 B · [流派B-某哲学] — [50字理由]
   ...

方向 C · [流派C-某哲学] — [50字理由]
   ...

方向 D · [流派D-某哲学] — [50字理由]
   ...
```

每个方向生成一个轻量 HTML Demo（mid-fi），让用户直观对比后选择。

## 反收敛自检

交付方向顾问前，必须逐项自检：

- 4 个方向是否来自 4 个流派，而不是 4 个同色系极简变体？
- 是否至少有 1 个方向来自实验先锋派或感性叙事派？
- 是否至少有 1 个方向明确说明生产级落地方式？
- 是否说明了每个方向的风险档位？
- 是否把事实依据和视觉假设分开？
- 是否避免了「高级感 = 深色渐变 + 大字 + 卡片」？

如果答案有任何一个是否定，重跑三锚点采样。
