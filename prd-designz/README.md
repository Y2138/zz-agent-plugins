# PRD Designz

面向 PRD 到 UI 工作流的设计与原型 skill 集。

## Skills

- **design-md**：从需求创建 DESIGN.md 和高保真 HTML 原型，适用于新产品或页面设计方向。
- **project-ui-skill-builder**：分析已有项目 UI，提取 Design Token 和组件模式，生成可复用的项目专属原型 skill。
- **project-ui-prototyper**：使用已有项目 UI 规则，从 PRD、需求、截图、线框图或草图生成与项目一致的 DESIGN.md 和 HTML 原型。

## 使用场景

- 从需求建立新产品设计方向
- 将现有产品 UI 系统提取为可移植的 agent 可读规则
- 生成项目专属原型 skill，供未来 agent 做 PRD 转原型或草图转原型
- 将 PRD 页面、产品草图或线框图转化为匹配已有项目 UI 系统的原型
